# chinese_subtext —— Echo 中文潜台词解码器 · 语料库 V1

本仓库是 Echo 项目的种子语料库，用于训练和评测「中文潜台词解码」能力：
把一句日常应答（如「行吧」「算了」「随便」）还原成字面义、真实意图、情绪与得体替代回复。

## 文件

| 文件 | 说明 |
|---|---|
| `corpus_v1.json` | 10 条种子样本，覆盖 5 个高危词：行吧 / 算了 / 随便 / 改天 / 再看看 |
| `README.md` | 本文件 |

## `corpus_v1.json` 结构

严格的 JSON 数组，每个元素字段固定为：

```json
{
  "id": 1,
  "scene": "宿舍",
  "dialogue": [
    {"speaker": "对方", "text": "原话"},
    {"speaker": "我", "text": "回应"}
  ],
  "target_phrase": "行吧",
  "literal": "字面英文",
  "intent": "真实意图",
  "emotion": "情绪",
  "alternative": "得体回复"
}
```

- `dialogue` 固定两轮，顺序为「对方」→「我」。
- `target_phrase` 是高危词，出现在「我」的回应里。
- `literal` 是该回应在语境下的字面英文直译。
- `alternative` 是同一处境下更得体、不依赖潜台词的表达。

## 数据来源说明（重要）

原始计划是从开源闲聊语料中「提取」含上述高危词的双人对话，实际执行后发现语料不满足要求：

- **豆瓣多轮**（`MarkWuNLP/MultiTurnResponseSelection`，test.txt，1000 条去重对话）：
  是论坛问答串，五个词合计仅 9 处命中，且是标题式提问而非双人对话。
- **小黄鸡语料**（`candlewill/Dialog_Corpus`）：命中量足够（算了 836、随便 486、
  改天 54、行吧 39、再看看 5），但上下文随机、多为机器人应答，不存在可标注的真实潜台词。

因此 V1 的 10 条样本为**人工撰写的种子样本**，场景与话术参照中文日常语用的常见模式，
不是从上述语料直接抽取的原文。后续版本应替换为真实采集并双人标注的数据。

## 已知局限

1. 规模仅 10 条，只能作为格式基准与回归测试，不具备训练价值。
2. 场景集中在宿舍 / 办公室 / 情侣 / 社交 / 求职 / 消费六类，未覆盖家庭长辈、上下级等高风险场景。
3. 只有一个标注者，`intent` 与 `emotion` 无标注一致性数据。

## 许可

自有内容，随项目许可发布。第三方语料（豆瓣多轮、小黄鸡）未纳入本仓库，
再次分发前需单独确认其许可。
